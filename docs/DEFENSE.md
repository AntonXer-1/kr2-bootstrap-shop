# КР №2 — что показать преподавателю

Чернышев Антон Дмитриевич, ЭФБО-02-25.

Короткое вступление: «Я сделал отдельную версию учебного магазина на Bootstrap. КР №1 написана на собственном CSS и осталась в другом репозитории. Здесь готовая сетка и компоненты Bootstrap, а custom.css содержит только небольшие настройки. Серверной обработки заявок нет».

## Четыре доработки на странице и в коде

| Доработка | Что нажать или открыть | Что показать в VS Code |
| --- | --- | --- |
| Локальный Bootstrap | Открыть сайт без внешних CDN-зависимостей | `vendor/bootstrap/css/bootstrap.min.css`, `vendor/bootstrap/js/bootstrap.bundle.min.js`; в `head` HTML относительные пути |
| Tabs | На странице клавиатуры переключить «Описание» и «Характеристики» | `product.html`: `nav nav-tabs`, `data-bs-toggle="tab"`, `data-bs-target="#specifications"`, панели `tab-pane` |
| Carousel | Там же нажать стрелку картинки, появится вид сбоку | `product.html`: `#productCarousel`, два `carousel-item`, кнопки `data-bs-slide="prev/next"` |
| Pagination | В каталоге нажать «2» и вернуться на «1»: товары разные | `catalog.html` и `catalog-page-2.html`: `pagination`, `page-item`, `page-link`, `aria-current="page"`, разные `href` |

Не говорить, что это четыре разные категории оценивания: tabs, carousel и pagination входят в одну категорию дополнительных компонентов PDF. Это согласованный список четырёх доработок.

## Обязательная часть

1. `index.html`: меню `navbar`, вводный hero-блок, преимущества и популярные товары.
2. `catalog.html`: `container → row g-4 → col-12 col-md-6 col-lg-4 → article.card`. В 12-колоночной сетке 12 — вся ширина, 6 — половина, 4 — треть. На ширинах от 768 px две карточки, от 992 px три. `g-4` — промежутки.
3. Прокрутить страницу: шапка с `sticky-top` остаётся сверху. На телефоне кнопка раскрывает `collapse`, этим управляет JS Bundle.
4. `product.html`: цена, `badge`, описание, таблица и кнопки `btn` разных вариантов.
5. Нажать «Заказать»: `modal` показывает правильный товар. `data-bs-toggle="modal"` открывает окно с ID из `data-bs-target`; `data-bs-dismiss="modal"` закрывает. В `js/demo.js` название берётся из `data-product` кнопки.
6. Перейти к `order.html`: выбранный товар сохранён. `form-control` — поля, `form-select` — товар, `input-group` — +7 с телефоном, `form-check` — согласие. `label for` совпадает с `id` поля; `name` обозначает имя данных.
7. Нажать проверку с пустыми полями или плохим email — браузер показывает ошибку. С корректными вымышленными данными и согласием появляется `alert-success`. Исходная подсказка — `alert-info`.
8. Открыть `css/custom.css`: шрифт, фон hero и несколько небольших правил. Сетку и компоненты не переписывали.
9. Показать `README.md`, его изменение в коммите, вкладку GitHub Commits и итоговый Pull Request. Ссылка для СДО — репозиторий, не только опубликованный сайт.

## Что важно не перепутать

- Bootstrap-сетка — стандартно Flexbox, а не собственный CSS Grid из КР №1.
- `sticky-top` — position sticky; это не position fixed. Она удерживает шапку вверху после достижения верхнего края.
- Наш Bootstrap modal — не нативный тег dialog из старого проекта.
- Пагинация — обычные переходы на другую HTML-страницу, а не запросы к серверу базы данных.
- Карусель не крутится сама, изображения переключает посетитель. SVG — условные схемы, не реальные фотографии.
- `preventDefault()` отменяет отправку формы. Администратору нечего смотреть: данные не хранятся.
- Сначала подключается Bootstrap CSS, затем custom.css; интерактивность требует JS Bundle.
