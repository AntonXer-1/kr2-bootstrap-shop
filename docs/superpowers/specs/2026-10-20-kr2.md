# КР №2 Bootstrap

Выполнить обязательные требования исходного PDF КР №2 в отдельном репозитории kr2-bootstrap-shop, сохранив тему учебного магазина и простое оформление. КР №1 не менять. Четыре согласованные доработки: локальный Bootstrap 5.3.8, tabs описания и характеристик, carousel двух схем клавиатуры, настоящая пагинация шести товаров по три на странице.

Четыре обязательные страницы: index, catalog, product, order; дополнительная catalog-page-2 нужна для пагинации. Использовать Bootstrap container/row/col-12/col-md-6/col-lg-4/g-4, navbar с мобильным collapse и sticky-top, card, btn, badge, alert, modal, form-control/form-select/input-group/form-check. Небольшой custom.css после Bootstrap. Без сборщика, CDN и backend. Форма проверяется браузером, показывает учебный результат и ничего не отправляет. Без JavaScript отправка отключена.
