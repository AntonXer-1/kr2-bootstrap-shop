# KR2 Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выполнить КР №2 и подготовить ответы для защиты 7, 8 и КР №2.

**Architecture:** Статические HTML-страницы, локальные Bootstrap CSS и JS Bundle, небольшой custom.css и demo.js. Каталог состоит из двух страниц с разными товарами.

**Tech Stack:** HTML, CSS, JavaScript, Bootstrap 5.3.8, Playwright для проверки.

**Spec:** docs/superpowers/specs/2026-10-20-kr2.md

## Global Constraints

- КР №1 не менять, работать в отдельном kr2-bootstrap-shop.
- Только четыре согласованных улучшения, простое оформление без backend/CDN.
- Учебные формы ничего не передают; отправка без JS отключена.
- Ответы на 17+22+20 вопросов, ФИО и группа в README.

## Review Focus

- Неверный email и непринятое согласие не дают учебный успех.
- Выбранный товар не теряется при переходе из карточки через modal к форме.
- После закрытия modal прокрутка и фокус восстанавливаются.
- На телефоне меню раскрывается, карточки не выходят за экран.
- Пагинация действительно меняет товары, все локальные ссылки существуют.
