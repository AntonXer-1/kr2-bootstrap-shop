# Учебный интернет-магазин — КР №2

Чернышев Антон Дмитриевич, группа ЭФБО-02-25.

Отдельная реализация учебного магазина на Bootstrap. Планируются локальное подключение Bootstrap, вкладки и карусель на странице клавиатуры, пагинация каталога. Проект учебный: продажи не осуществляются, формы не передают данные.
